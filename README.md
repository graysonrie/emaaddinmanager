## EMA Addin Launcher
For internal company use at EMA Engineering & Consulting

Features
- Centralized Revit addin management
- User management for admins
- Easy installation/deinstallation of addins
- Submit support tickets
- Notifications upon addin updates

Built with Next.js + Tauri
